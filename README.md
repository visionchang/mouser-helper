# 鼠标助手（MouseHelper）

轻量级 macOS 菜单栏应用，为普通鼠标提供**按住中键 + 左右滑动 = 横向滚轮滚动**体验，同时完整保留正常的中键点击（如浏览器新标签页打开链接、关闭标签页）。

## 功能特点

- **按住中键左右滑动即可横向滚动**：默认滑动时光标锁定原地不动，适用于表格、代码编辑器、时间轴、看板、网页等所有支持横向滚动的 macOS 应用；鼠标侧键完全不受影响。
- **无损保留正常中键点击**：短按/轻点中键（位移小于防误触阈值）自动还原标准中键点击。
- **两种滑动方向可选**：
  - **视口跟随**：向右滑鼠标 → 查看右侧内容（类似向右拨动横向滚轮）
  - **页面跟随**：向右滑鼠标 → 将页面向右拖动（类似触控板自然滚动 / 抓手工具）
- **按住右键画手势（8 组高频手势 + 炫酷霓虹拖影 + 实时胶囊提示）**：
  - 内置 4 个单向手势（`←`/`→`/`↑`/`↓`）与 4 个折线组合手势（`↓→`/`↓←`/`↑→`/`↑←`），每项均可独立开启/关闭并自由切换绑定动作（后退、前进、关闭/恢复/切换标签页、调度中心、切换桌面空间、显示桌面、最小化等 18 种动作）。
  - 仅右键画手势时展示霓虹渐隐拖影（4 种主题配色）与实时毛玻璃动作提示胶囊；轻点右键无损还原右键菜单，多划一笔自动取消防误触。
- **普通鼠标滚轮反向滚动（可选）**：仅反转普通机械滚轮鼠标的滚动方向，不修改 macOS 系统设置，不影响触控板和 Apple Magic Mouse。
- **光标位置锁定（默认开启，可切换）**：滑动期间锁定光标位置，避免滑出目标窗口或顶到屏幕边缘。
- **实时参数调节与内置测试区**：支持调节灵敏度、防误触阈值、平滑像素 / 步进滚轮模式、可选开启上下滑动、开机自启动。

## 构建与运行

```bash
./scripts/build_app.sh
open build/MouseHelper.app
```

可以将 `build/MouseHelper.app` 拖入 `/Applications`（应用程序）文件夹中长期使用。

## 首次使用权限说明

由于应用需要监听鼠标右键拖拽并发送横向滚轮事件，首次启动时需要授予 macOS **辅助功能（Accessibility）** 权限：

1. 启动后点击顶部菜单栏图标，点击「打开辅助功能设置」。
2. 在 **系统设置 → 隐私与安全性 → 辅助功能** 中找到并开启 `MouseHelper`（如列表中没有，可点击 `+` 手动添加 `MouseHelper.app`）。
3. 授权完成后应用会自动开始生效，无需手动重启。
